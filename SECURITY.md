# Security policy

## Supported versions

DocMind is a documentation scaffold and has no production release or supported runtime version yet. Security reports about future code, dependencies, access control, or data exposure are still welcome.

| Version | Security fixes |
| --- | --- |
| Current scaffold | No runtime code yet |
| Future releases | To be announced |

## Report a vulnerability

Do not open a public issue or pull request with exploit details, credentials, or private documents. If the repository offers **Report a vulnerability** under GitHub's Security tab, use that private reporting form. Otherwise, open a short public issue requesting a private reporting channel without disclosing the vulnerability itself.

Include the affected component, impact, steps to reproduce with synthetic data, and a suggested mitigation if known. The maintainer will acknowledge reports when possible, assess impact, and coordinate a fix before public disclosure. No response or fix deadline is promised at this pre-release stage.

Do not test against systems or data you do not own or have permission to assess.
